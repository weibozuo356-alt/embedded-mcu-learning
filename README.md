# Embedded MCU Learning

这是我的嵌入式 MCU 学习仓库，用于记录从 C 语言基础到 STM32、常用外设、通信协议、FreeRTOS 和综合项目的完整学习过程。

这个仓库不仅保存代码，也会记录实验现象、遇到的问题、排查过程和阶段总结。目标不是快速堆积资料，而是沿着一条清晰的主线持续学习，并逐步形成能够独立完成嵌入式项目的能力。

## 总体目标

完成这条学习主线：

> C 语言基础 → STM32 基础 → 常用外设 → 通信协议 → DMA 与底层机制 → 综合项目 → FreeRTOS → 项目完善与实习准备

最终希望能够：

- 熟练阅读、修改和编写嵌入式 C 代码
- 理解 MCU、GPIO、中断、定时器和常用通信接口的工作方式
- 能够阅读芯片数据手册、参考手册和外设文档
- 能够独立连接、驱动和调试常见传感器及外设
- 掌握基础的模块化设计、版本管理和问题排查方法
- 能够使用 FreeRTOS 完成基础多任务应用
- 独立完成至少两个可展示的 STM32 综合项目
- 将学习成果整理成适合复习和展示的 GitHub 项目

## 学习原则

1. **只保留一条主线**：当前阶段以 C 语言和 STM32 为核心，不同时展开 Linux、FPGA、Zephyr 等方向。
2. **课程负责引导，动手负责掌握**：每个知识点都要亲自编写、编译、运行和观察结果。
3. **先会使用，再理解底层**：先通过实验形成直观认识，再学习寄存器、时钟树和启动过程。
4. **AI 作为助教**：主要用于解释、出题、代码审查和协助排错，不直接代替完整学习过程。
5. **记录排错过程**：不仅记录“成功代码”，也记录问题现象、原因、验证方法和解决方案。
6. **阶段结束必须做项目**：用项目检验是否真正掌握，而不是只以看完课程为标准。

## 学习路线

### 阶段 1：C 语言基础

**目标：** 能够看懂、修改并独立编写基础 STM32 程序所需的 C 代码。

主要内容：

- 变量、数据类型和运算符
- `if`、`switch`、`for` 和 `while`
- 函数、参数、返回值和作用域
- 数组、字符串和指针
- 结构体、枚举和类型定义
- 位运算
- `const`、`static` 和 `volatile`
- `.c`、`.h` 文件与模块化编程
- 指针传参和基础内存概念

阶段成果：

- 独立完成基础语法练习
- 编写若干小程序并进行简单调试
- 能够解释函数、指针、结构体和位运算在代码中的作用
- 能够阅读简单的 STM32 HAL 示例代码

### 阶段 2：STM32 基础

**目标：** 理解 MCU 如何通过引脚、定时器和中断与现实世界交互。

建议顺序：

1. 开发环境与工程结构
2. GPIO 输出与输入
3. LED 和按键
4. 外部中断与 NVIC
5. 定时器
6. PWM
7. ADC

阶段项目：

- LED 闪烁
- 按键控制 LED
- 按键中断
- PWM 呼吸灯
- 蜂鸣器或舵机控制
- ADC 模拟量采集

### 阶段 3：通信协议与外设驱动

**目标：** 能够根据资料连接并驱动常见外设。

建议顺序：

1. UART：串口输出、接收和基础数据协议
2. I2C：OLED 与传感器
3. SPI：屏幕、Flash 或传感器
4. CAN：作为后续汽车电子或工业控制方向的扩展

阶段成果：

- STM32 与电脑进行串口通信
- OLED 显示采集数据
- 驱动至少一个 I2C 或 SPI 传感器
- 能够根据数据手册定位地址、寄存器和时序信息

### 阶段 4：DMA 与 MCU 底层机制

**目标：** 从“会调用接口”逐步过渡到“理解程序如何运行”。

主要内容：

- DMA 基础与常用场景
- STM32 时钟树
- NVIC 与中断机制
- 外设寄存器
- Flash 与 SRAM
- ARM Cortex-M 基础
- 启动文件与中断向量表
- 编译、链接和程序启动的基本过程

阶段成果：

- 使用 DMA 完成一次数据收发或采集实验
- 能够结合参考手册解释一个常用外设的配置过程
- 能够大致说明 STM32 从复位到执行 `main` 的过程

### 阶段 5：第一个综合项目

**建议项目：STM32 环境监测系统**

可包含：

- 温湿度或其他环境传感器
- OLED 显示
- ADC 数据采集
- UART 数据输出
- 按键切换页面
- 简单的告警功能

**目标：** 不照搬完整成品，从需求拆分、接线、编码到调试独立完成，并编写项目说明。

### 阶段 6：FreeRTOS

**前提：** 已经具备 GPIO、中断、定时器和通信外设的裸机开发经验。

主要内容：

- Task 与任务状态
- 优先级和调度器
- Queue
- Semaphore 与 Mutex
- 软件定时器
- 事件组
- 任务间通信与资源保护
- 栈、堆和常见 RTOS 调试问题

阶段项目：

将环境监测系统重构为多任务版本，例如：

- 传感器采集任务
- 屏幕显示任务
- 串口通信任务
- 按键与告警任务

### 阶段 7：项目完善与实习准备

**目标：** 将知识转化为可展示、可讲解的工程能力。

主要任务：

- 完成至少两个综合项目
- 为项目补充 README、硬件清单、接线说明和演示图片
- 整理关键问题及排查过程
- 学习 Git 的基本工作流
- 复习 C、STM32、通信协议和 FreeRTOS 常见问题
- 阅读嵌入式实习岗位要求，按能力缺口补充学习
