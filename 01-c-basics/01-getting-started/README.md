# C 语言入门（Getting Started with C）

## 1. C 程序的基本结构

### 1.1 头文件

头文件可以理解为函数和声明的“说明书”。使用某个标准库函数前，需要包含相应的头文件，让编译器提前知道函数的相关信息。

例如，使用 `printf()` 需要包含：

```c
#include <stdio.h>
```

### 1.2 `main()` 主函数

`main()` 是 C 程序的入口，程序从这里开始执行。初学阶段推荐写成：

```c
int main(void)
{
    return 0;
}
```

- `int`：函数返回一个整数。
- `main`：主函数的名称。
- `void`：表示该函数不接收参数。
- `return 0;`：表示程序正常结束。

### 1.3 程序主体

程序主体通常由变量、函数调用和运算组成。一般情况下，语句按照从上到下的顺序执行，多数语句以英文分号 `;` 结尾。

## 2. 函数

函数是一段用于完成特定功能的代码。一个函数调用通常包含函数名、圆括号和参数。

```c
printf("Hello, world!\n");
```

这里的函数名是 `printf`，字符串 `"Hello, world!\n"` 是传给它的参数。

## 3. `printf()` 函数

`printf()` 用于向终端输出文字或变量。`\n` 表示换行，通常优先使用它；在 Windows 中看到的 `\r\n` 也是一种换行形式。
