# 使用 `scanf()` 输入（Input with `scanf()`）

## 1. `scanf()` 函数

`scanf()` 用于从标准输入读取数据，并把读取到的值保存到变量中。

```c
scanf("格式说明符", &变量名);
```

例如，读取一个整数：

```c
int number;
scanf("%d", &number);
```

## 2. 变量与内存地址

变量可以理解为保存数据的存储空间，变量名是访问这块空间时使用的名称；地址则表示这块存储空间在内存中的位置。

地址本身不是容器。`&` 是取地址运算符，写在变量名前面可以得到该变量的内存地址：

```c
&number
```

`scanf()` 需要变量的地址，因为它要把用户输入的数据写入该变量所在的内存位置。

## 3. 输入和输出

```c
char letter;

scanf(" %c", &letter);
printf("%c\n", letter);
```

`%c` 前面的空格可以跳过输入缓冲区里之前残留的空白字符，例如换行符。当前程序只读取第一个字符时，原来的 `"%c"` 也可以正常工作。

## 4. 语句拆分

以 `scanf("%d", &number);` 为例：

- `scanf`：函数名。
- `()`：函数调用的圆括号。
- `"%d"`：格式字符串。
- `&number`：变量的地址。
- `,`：分隔不同参数。
- `;`：结束这条语句。
