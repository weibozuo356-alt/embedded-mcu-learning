# 条件语句（Conditional Statements）

## 1. `if` 语句

`if` 用于判断条件。条件为真时，执行花括号中的代码：

```c
if (条件)
{
    程序语句;
}
```

- `=`：把右侧的值赋给左侧变量。
- `==`：判断两个值是否相等。

## 2. `if...else` 语句

```c
if (条件)
{
    程序语句;
}
else
{
    程序语句;
}
```

条件为真时执行 `if` 分支，否则执行 `else` 分支。

## 3. `if...else if...else` 语句

```c
if (条件一)
{
    程序语句;
}
else if (条件二)
{
    程序语句;
}
else
{
    程序语句;
}
```

- `if...else if...else`：从上到下判断，一旦某个条件成立，后续分支不再判断。
- 多个独立 `if`：每个 `if` 都会分别判断，可能执行多个分支。

## 4. 嵌套条件语句

`if` 或 `else` 内部还可以继续使用 `if`。这称为嵌套条件语句。阅读嵌套逻辑时，应从外层向内逐层判断。

## 5. 比较与逻辑运算符

### 5.1 比较运算符

| 含义 | 运算符 |
| --- | --- |
| 小于 | `<` |
| 大于 | `>` |
| 等于 | `==` |
| 小于等于 | `<=` |
| 大于等于 | `>=` |
| 不等于 | `!=` |

### 5.2 逻辑运算符

| 含义 | 运算符 |
| --- | --- |
| 与 | `&&` |
| 或 | `\|\|` |
| 非 | `!` |

```c
if (a >= 0 && a < 5)
{
    printf("a is between 0 and 5\n");
}
```
