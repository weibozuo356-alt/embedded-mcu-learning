# 循环（Loops）

循环可以让程序在满足条件时重复执行一段代码，从而减少重复代码。

## 1. `while` 循环

`while` 会先判断循环条件。条件为真时执行循环体，然后再次判断条件；条件为假时结束循环。

```c
while (循环条件)
{
    循环体;
}
```

下面的程序输出 `0` 到 `66`：

```c
int i = 0;

while (i < 67)
{
    printf("%d\n", i);
    i++;
}
```

如果忘记更新循环变量，条件可能永远成立，程序就会陷入无限循环。

## 2. 自增运算符

`i++` 和 `++i` 都能让 `i` 增加 `1`，但它们作为表达式的一部分时有所区别：

- `i++`：先产生自增前的值，再让 `i` 加 `1`。
- `++i`：先让 `i` 加 `1`，再产生自增后的值。

当它们单独作为一条语句时，最终效果相同：

```c
i++;
++i;
```

不要写成 `i = i++;`。这种写法会在同一个表达式中多次修改 `i`，属于未定义行为。

## 3. `for` 循环

`for` 把初始化、循环条件和计数器更新集中写在一行：

```c
for (初始化; 循环条件; 计数器更新)
{
    循环体;
}
```

例如：

```c
for (int i = 0; i < 67; i++)
{
    printf("%d\n", i);
}
```

在 `for` 中定义的变量 `i` 只在该循环及其循环体内有效。即使循环体只有一条语句，也建议保留花括号，让结构更清楚。

## 4. 无限循环与 `break`

条件始终为真时会形成无限循环：

```c
while (1)
{
    /* 重复执行 */
}
```

`break` 会立即结束它所在的**最内层**循环，然后从循环后的语句继续执行。它既能用于无限循环，也能用于普通的 `while`、`for` 和 `do...while` 循环。

## 5. 嵌套循环

一个循环内部可以包含另一个循环。外层循环每执行一轮，内层循环通常会从头执行完整的一轮。

```c
for (int row = 0; row < 3; row++)
{
    for (int column = 0; column < 2; column++)
    {
        printf("row=%d, column=%d\n", row, column);
    }
}
```

嵌套循环中的 `break` 默认只结束它直接所在的那一层循环。

## 6. `do...while` 循环

`do...while` 会先执行一次循环体，再判断条件，因此循环体至少执行一次。

```c
do
{
    循环体;
} while (循环条件);
```

注意：`while (循环条件)` 后面需要写分号 `;`。
