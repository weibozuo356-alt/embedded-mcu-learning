# 变量与算术运算（Variables and Arithmetic）

## 1. 变量

变量是有名称的存储空间，用来保存程序运行过程中可能使用或改变的数据。变量必须先定义，再使用。

```c
数据类型 变量名;
数据类型 变量名 = 初始值;
```

变量名不能使用 C 语言关键字，例如 `int`、`if` 和 `return`。虽然某些库函数名在语法上可以作为变量名，但不应使用 `printf` 等函数名，以免造成混淆。

## 2. 基本数据类型

### 2.1 `int` 整型

`int` 用于保存整数，包括正数、负数和零。

```c
int number = 10;
```

`int` 的具体范围与编译器和平台有关，不能固定认为是 `-32768` 到 `32767`。当前常见环境中的 `int` 通常是 32 位。

### 2.2 `float` 浮点型

`float` 用于保存带小数的数据，通常能可靠表示大约 6～7 位**有效数字**，并不等于“小数点后固定六位”。

```c
float pi = 3.14f;
```

常量末尾的 `f` 表示这是一个 `float` 类型的浮点常量。

### 2.3 `char` 字符型

`char` 用于保存单个字符，赋值时使用英文单引号：

```c
char letter = 'G';
```

字符在计算机内部以整数编码保存，ASCII 是常见的字符编码表之一。

## 3. 赋值运算符

单个等号 `=` 用于把右侧的值保存到左侧变量中：

```c
int x = 6;
x = x + 1;
```

- `=`：赋值。
- `==`：判断两边是否相等。

## 4. 算术运算

| 运算 | 运算符 |
| --- | --- |
| 加法 | `+` |
| 减法 | `-` |
| 乘法 | `*` |
| 除法 | `/` |

一般先计算乘法和除法，再计算加法和减法。需要明确顺序时，应使用圆括号。两个整数相除得到整数结果，小数部分会被截去，例如 `5 / 2` 的结果是 `2`。

## 5. `printf()` 格式说明符

| 数据类型 | 格式说明符 | 示例 |
| --- | --- | --- |
| `int` | `%d` | `printf("%d\n", number);` |
| `float` | `%f` | `printf("%f\n", value);` |
| `char` | `%c` | `printf("%c\n", letter);` |

`%.2f` 表示输出浮点数时保留两位小数。
