# 函数与作用域（Functions and Scope）

函数是一段用于完成特定任务、可以被重复调用的代码。合理使用函数能够减少重复代码，并让程序结构更清晰。

## 1. 函数的基本结构

函数定义通常包含返回类型、函数名、参数列表和函数体：

```c
返回类型 函数名(参数列表)
{
    函数体;
}
```

例如：

```c
int add(int first, int second)
{
    return first + second;
}
```

## 2. 返回类型与返回值

返回类型说明函数执行结束后会返回哪种类型的数据。

### 2.1 返回整数的函数

```c
int add(int first, int second)
{
    return first + second;
}
```

这里的 `int` 表示函数返回一个整数，`return` 后面的表达式就是返回值。

函数声明的返回类型应与实际返回值相匹配。对于返回非 `void` 类型的普通函数，应确保所有可能的执行路径都有合适的 `return`。

### 2.2 无返回值的函数

`void` 表示函数不返回值：

```c
void print_message(void)
{
    printf("Hello\n");
}
```

`void` 函数可以接收参数，也可以不接收参数。它是否使用指针与返回类型没有必然关系。

### 2.3 其他返回类型

函数也可以返回 `char`、`float` 等其他类型。在嵌入式程序中还经常看到 `uint16_t` 等固定宽度整数类型，它们定义在 `<stdint.h>` 中：

```c
#include <stdint.h>

uint16_t read_value(void);
```

正确拼写是 `uint16_t`，不是 `unit16_t`。

## 3. `main()` 函数

当前电脑环境中的标准写法是：

```c
int main(void)
{
    return 0;
}
```

- 第一个 `int` 表示 `main()` 返回整数。
- 参数列表中的 `void` 表示不接收参数。
- `return 0;` 通常表示程序正常结束。

`void main(void)` 不是标准 C 写法。以后编写 STM32 程序时，也优先按照工程模板使用 `int main(void)`，不要自行改成 `void main(void)`。

## 4. 函数参数

参数用于把调用位置的数据传入函数。定义多个参数时，必须分别写出每个参数的类型：

```c
int add(int first, int second)
{
    return first + second;
}
```

调用函数时写入的值称为实参：

```c
int result = add(10, 20);
```

函数定义中的 `first` 和 `second` 称为形参。C 语言默认按值传递参数，函数得到的是实参值的副本。在函数内部修改普通形参，不会修改调用位置的原变量。

如果函数不接收参数，应明确写成：

```c
void print_message(void);
```

## 5. 函数声明、定义与调用

### 5.1 函数声明

函数声明也称为函数原型，它提前告诉编译器函数的返回类型、名称和参数类型：

```c
int add(int first, int second);
```

声明以分号结束，没有函数体。

### 5.2 函数定义

函数定义包含完整的函数体：

```c
int add(int first, int second)
{
    return first + second;
}
```

函数可以直接定义在 `main()` 前面，也可以先在 `main()` 前声明，再把定义写在 `main()` 后面。

### 5.3 函数调用

调用函数时使用函数名和圆括号：

```c
int result = add(10, 20);
printf("%d\n", add(3, 4));
```

有返回值的函数可以把结果保存到变量中，也可以直接作为表达式的一部分使用。无返回值函数只执行功能，不能把它的结果赋给变量。

## 6. 变量作用域

作用域表示一个名称可以在源代码的哪些位置被访问。

### 6.1 局部变量

在函数或代码块内部定义的变量是局部变量，只能在所在函数或代码块中使用：

```c
int main(void)
{
    int local_value = 10;

    return 0;
}
```

函数参数也是局部变量。

### 6.2 全局变量

在所有函数外部定义的变量具有文件作用域。从定义位置开始，同一源文件后面的函数都可以访问它：

```c
int global_value = 5;
```

全局变量使用方便，但多个函数都能修改它，程序变大后会增加理解和调试难度。可以用参数和返回值表达的数据，通常优先通过参数和返回值传递。

### 6.3 同名变量与遮蔽

局部变量与外层变量同名时，局部变量会暂时遮蔽外层变量：

```c
int value = 5;

int main(void)
{
    int value = 10;
    printf("%d\n", value); /* 输出 10 */

    return 0;
}
```

初学阶段应尽量避免使用容易混淆的同名变量。

## 7. 程序运行流程

本课程序的主要运行过程是：

1. 程序从 `main()` 开始。
2. `main()` 调用 `calculate_result(23, 5)`。
3. 参数值分别复制给 `value` 和 `offset`。
4. 函数计算并通过 `return` 返回结果 `235`。
5. 返回值保存到 `local_result`。
6. `main()` 输出局部结果和全局变量。
7. 调用无返回值函数 `print_separator()`。
8. `main()` 返回 `0`，程序结束。
